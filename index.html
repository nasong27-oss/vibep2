바이브코딩 그거 어떻게 하는건데?

바이브코딩을 이미 경험하고 있으신 분이라면 이 문서를 읽을 필요가 없습니다.
바이브코딩 해보라는데, 그거 뭐 어떻게 하는건데? 하는 분들을 위한 경험 공유 입니다.

바이브코딩을 한번도 해 보지 않으신 분들이라면 코딩부터 배포까지 한방에 해결해 주는 플랫폼을 추천합니다.
사용 경험은 ChatGPT와 거의 유사하며 몇줄의 프롬프트만 넣어도 근사한 초안을 완성해 줍니다.

Replit 바로가기 ↗

그런데 이게 좀 비쌉니다. 제대로 좀 해보려면 일단 월 구독을 해야하고 (22달러), 이 구독에서 제공하는 크레딧은 며칠, 좀 많이 하면 몇시간이면 소모되고 추가 크레딧에 과금이 됩니다.
한달에 20만원 금방 쓰게 됩니다.

그럴 수는 없는 노릇이니, 일단 한번 맛을 보셨으면 여러 플랫폼을 교차해 활용하는 방식을 추천 드립니다.

웹페이지나 앱을 만든다고 생각해 보시면,
1) 기획 방향을 설정해 기획하고 2) 구현 디자인/개발을 통해 구현해서 3) 배포 남들이 쓸수 있게 배포하는 과정입니다.

바이브코딩은 1)번을 프롬프트화 시켜서 입력하면 2)번을 자동으로 해주는 과정입니다.
그래서 나온 산출물을 3)번 배포의 과정을 통해서 서비스화 시키는 것이죠. 여기에 각각을 담당하는 툴들이 있어요.

시작해 보겠습니다.

Step by Step
01

코드를 보관할 집, GitHub

코드를 관리하는 공간이 필요합니다. 개발자들이 쓰는 그 GitHub, 맞습니다. 여러분도 이제 코딩을 하니 코드를 여기서 관리합니다. 이후 모든 플랫폼이 GitHub에서 코드를 불러오기 때문에 필수입니다.

GitHub ↗

★ 필수 — 모든 플랫폼의 연동 기반

02

바이브코딩 툴 선택

대화 형식으로 요청을 하면 코드를 만들어 GitHub에 넣어주는 도구입니다. 툴은 많습니다. 너무 많으니 취향껏 선택하시면 되지만 추천 드리는 것은 클로드 코드와 커서 프로입니다.

Cursor Pro는 비개발자 입문자에게 친숙한 인터페이스를 제공합니다. Claude Code는 터미널 기반으로 강력하지만 약간의 진입장벽이 있습니다. 처음엔 Cursor부터 시작해 보세요.

Cursor Pro ↗ Claude Code ↗ Replit (입문용) ↗ Lovable ↗ Bolt.new ↗

★ 입문자 추천 — Cursor Pro

03

가입 · 연동 · 코딩 시작

바이브코딩툴을 선택했으면 가입하고, 필요하면 구독도 하고, 가장 중요한 Github 계정과 연동합니다. Github계정과 연동할때 Repo. 를 선택하라고 할겁니다. Repository이고, 코드의 집합, 즉 우리가 만들 서비스입니다. 그러니 이름은 생각하시는 서비스의 이름으로 지으면 됩니다. 미리 Github에 만들어 놓으셔도 되고 연동하면서 새로 만들수도 있습니다.

① 요청 바이브코딩 툴에 대화하듯이 아무거나 요청을 하면
② 생성 코드를 만들어 지정한 Github Repository에 코드를 넣어 줍니다. 그럼 서비스가 만들어진거에요.
③ 완료 Github에 들어가서 코드 확인하고 그러실 필요 없습니다. 어차피 봐도 모르고요. 끝났습니다 하면 아 끝났구나 하면 됩니다.

여기까지 하면 코딩은 완료입니다.

04

배포 — 세상에 공개하기

코딩으로 완성된 서비스를 눈으로 확인하고 배포해서 남들도 써보게 해야겠죠? Vercel이라는 배포 툴을 활용합니다. 바이브 코딩 툴에서 그랬던 것처럼 Github 계정을 연동합니다. 연동하고 나면 Github의 Repo. 리스트가 보일거고요.

배포(Deploy) 버튼을 누르면 배포가 됩니다. 배포된 URL을 누르면 바이브코딩 툴에 요청해 만든 서비스가 짠 하고 나올거에요.

끝났습니다.

Vercel ↗ Netlify (대안) ↗

★ GitHub 연동 → Deploy 버튼 → URL 완성

겁먹지 말고, 일단 시작.
